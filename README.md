# Cattaro Ariya Sacca
**Idaṁ dukkhaṁ ariyasaccaṁ:** 
jātipi dukkhā, jarāpi dukkhā, byādhipi dukkho, maraṇampi dukkhaṁ, 
appiyehi sampayogo dukkho, piyehi vippayogo dukkho,
yampicchaṁ na labhati tampi dukkhaṁ—saṅkhittena pañcupādānakkhandhā dukkhā.

**Idaṁ dukkhasamudayaṁ ariyasaccaṁ:**
yāyaṁ taṇhā ponobbhavikā nandirāgasahagatā tatratatrābhinandin: kāmataṇhā, bhavataṇhā, vibhavataṇhā.

**Idaṁ dukkhanirodhaṁ ariyasaccaṁ:**
yo tassāyeva taṇhāya asesavirāganirodho cāgo paṭinissaggo mutti anālayo.

**Idaṁ dukkhanirodhagāminī paṭipadā ariyasaccaṁ:**
ayameva ariyo aṭṭhaṅgiko maggo, seyyathidaṁ

## Dhamma-kicca
Idaṁ dukkhaṁ ariyasaccan. Taṁ kho panidaṁ dukkhaṁ ariyasaccaṁ pariññeyyan. Taṁ kho panidaṁ dukkhaṁ ariyasaccaṁ pariññātan

Idaṁ dukkhasamudayaṁ ariyasaccan. Taṁ kho panidaṁ dukkhasamudayaṁ ariyasaccaṁ pahātabban. Taṁ kho panidaṁ dukkhasamudayaṁ ariyasaccaṁ pahīnan

Idaṁ dukkhanirodhaṁ ariyasaccan. Taṁ kho panidaṁ dukkhanirodhaṁ ariyasaccaṁ sacchikātabban. Taṁ kho panidaṁ dukkhanirodhaṁ ariyasaccaṁ sacchikatan

Idaṁ dukkhanirodhagāminī paṭipadā ariyasaccan. Taṁ kho panidaṁ dukkhanirodhagāminī paṭipadā ariyasaccaṁ bhāvetabban. Taṁ kho panidaṁ dukkhanirodhagāminī paṭipadā ariyasaccaṁ bhāvitan
